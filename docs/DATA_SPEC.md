## 2019년 상권 매쉬업

- **출처와 이용조건** · 제주데이터허브 공개 자료. 화면 근거에 자료명과 원출처 링크를 표시한다.
- **파일 확인** · `제주특별자치도_주제3_상권분석을 위한 유동인구에 따른 카드 매출액 변화 데이터 활용_매쉬업결과_19.csv`, 3,013,871바이트, 데이터 27,416행, CP949, SHA-256 `7a304ceef10f0b1a4d702800f80a20f9f643c60447ff564a6bd16cb32dd9ca0d`. `년월·읍면동명·업종명·성별·이용금액·방문인구`를 읽는다.

제주데이터허브에서 원본 CSV를 직접 내려받는다. 카드 이용금액(원)은 선택한 지역·기간·업종에 해당하는 관측 행의 합계다. 전체 업종은 관측된 업종·성별 행의 소계로 표시한다. 방문 유동인구는 같은 지역·월·성별에 걸쳐 같은 값이 반복되면 한 번만 반영한다. 결과는 월 누적 추정치를 합산한 값이다.

## 월별 입도 관광객 확정치

- **출처** · 제주특별자치도관광협회 작성, 제주관광공사 제주관광데이터랩 제공. 제공 페이지 갱신일은 2026-11-12이며, 실제 첨부파일의 마지막 관측월은 2026-09다.
- **사용 조건** · 공공누리 제1유형의 출처 표시 조건을 적용한다. 앱 결과 근거에 자료명, 제공처 링크, 원자료 작성기관을 표시한다. [공공누리 제1유형](https://www.kogl.or.kr/info/licenseType1.do)
- **파일 확인** · `입도관광객 전체_2026년09월 기준.xlsx`, SHA-256 `e90d0a3fe01949f66b536b1d0a5a4370432cb1f80747f847713f769934f75fd1`. `분석용 데이터` 시트의 `년도·월·구분·방문객수` 컬럼을 읽는다. 로컬 로딩은 openpyxl 3.1.5를 사용한다.
- **계산** · 월마다 `구분=전체`인 확정치 한 행을 사용한다. 두 해 같은 달의 차이는 올해 값에서 전년 값을 뺀 수다. 증감률은 차이를 전년 값으로 나누고 100을 곱한다. 전년 값이 0이면 증감률을 산정하지 않는다.
- **검산** · 2025-09 1,181,507명, 2026-09 1,123,339명. 차이 −58,168명, 증감률 −4.92%. [제주특별자치도관광협회 월별 확정 통계](https://www.visitjeju.or.kr/issue/stats/monthly.htm?_layout=print)

## 자료 선택과 결합

앱은 [카탈로그](../core/kg/catalog.json)에서 질문 지표와 연결된 자료, 지역 체계, 시간 집계 단위, 관측 범위, 검증된 결합 관계를 조회한다. 두 자료의 공통 월은 2019-01~2019-12다. 2026-09 결합 요청에는 공통 기간 밖이라는 안내와 함께 제주 전체·읍면동의 지역 차이를 보여준다. 등록된 검증 조인 관계는 없다.

두 원본 파일은 각각의 공식 페이지에서 준비해 로컬에 둔다. 파일이 없으면 앱 화면 상단에 파일명, 공식 페이지, 둘 위치가 표시되고, 있는 파일로 할 수 있는 분석은 그대로 실행된다. 참가자 제공 목록·예시 엑셀은 외부 배포 및 제3자 제공 제한을 따르며 실행에 사용하지 않는다.

## 처리 흐름

1. **질문 해석** · 규칙 기반 플래너가 질문·선택지에서 목적, 지역, 기간, 업종, 지표, 제외 월을 뽑아 분석 계획 JSON을 만든다. 후속 질문은 직전 계획을 복사해 언급한 조건만 바꾼다.
2. **자료 조회** · 카탈로그에서 지표에 맞는 자료, 지역 체계, 시간 단위, 관측 범위를 찾는다. 두 자료가 걸린 요청은 지역 체계·시간 단위·공통 관측 기간·검증된 결합 관계를 확인해 결합 여부를 정한다.
3. **로컬 집계** · 계획을 JSON Schema로 검증한 뒤 엔진이 허용된 필터·합계·추이·전년 동월 비교만 실행한다. 같은 자료와 조건이면 항상 같은 값이 나온다.
4. **결과와 근거** · 화면은 엔진 값으로 한 문장 답·표·그래프를 만들고, 출처·실제 관측월·제외한 달·계산 방법·품질 알림을 근거로 보여준다.

## 네트워크

- **설치 단계** · Python 패키지 설치(PyPI)와 두 공개 파일 내려받기에 필요하다.
- **실행 중** · 필요 없다. 외부 API·언어 모델·사용 통계 전송이 없고 화면은 `localhost`에서만 열린다. 글꼴과 로고도 로컬 파일을 쓴다.

## 향후 확장

- **지역 코드 매핑** · 센터 카드 자료의 `bjd`와 유동인구 자료의 `emd_cd`는 이름이나 자릿수만으로 같은 지역이라고 보지 않는다. 코드 정의·매핑표·매칭률을 확인한 뒤 카탈로그에 검증된 결합 관계로 등록한다.
- **센터 자료 70종** · 센터 예시 자료의 시트별 스키마를 등록 후보로 두고, 원자료가 연결되면 단위·기간 검사를 거쳐 분석을 연다. 현재 앱은 화면에 "스키마 확인 · 원자료 미연결"로만 표시한다.

외부 데이터와 오픈소스 목록은 [최종 결과물 안내](SUBMISSION_GUIDE.md)에 있다.
