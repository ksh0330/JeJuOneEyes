# 사용자 매뉴얼

센터 PC에서 앱을 처음 쓰는 방문자를 위한 안내다. 설치와 실행은 [앱 실행 안내](../app/README.md)를 따른다. 실행 후 브라우저에서 `http://localhost:8501`을 연다.

## 1. 자료 연결 확인

왼쪽 사이드바에서 두 파일의 연결 상태를 확인한다.

| 표시 | 뜻 | 할 일 |
| --- | --- | --- |
| 공개 CSV 연결됨 | 2019년 상권분석 매쉬업 CSV를 찾았다 | 없음 |
| CSV를 찾을 수 없습니다 | `data/local/`에 원래 파일명의 CSV가 없다 | [데이터 활용 명세](DATA_SPEC.md)대로 내려받아 두거나 경로를 입력 |
| 입도객 XLSX 연결됨 | 제주관광공사 2026년 9월 기준 XLSX를 찾았다 | 없음 |
| 전년 동월 비교를 하려면 … XLSX를 연결해 주세요 | `data/local/jeju-arrivals.xlsx`가 없다 | 공식 XLSX를 내려받아 저장하거나 경로를 입력 |

## 2. 질문하기

첫 화면 가운데의 질문 입력창에 쓰고 **분석하기**를 누르거나 ⌘+Enter(Windows는 Ctrl+Enter)를 누른다. 한글 조합 중 Enter로는 실행되지 않는다. 세 가지 입력 방법은 같은 분석 계획으로 이어진다.

1. **예시 질문.** 입력창 아래 **업무별 예시 질문** 탭의 버튼을 누르면 질문 입력창에 문장이 들어간다. 지역이나 월을 고친 뒤 **분석하기**를 누른다. 버튼 앞의 회색 배지는 해당 업무(소상공인, 도민·연구자, 기업 실무자, 공공기관)를 뜻한다. 위쪽 **내 업무** 선택은 예시 순서만 바꾸며, 이용할 수 있는 자료와 분석 범위는 같다.
2. **자연어.** 질문 입력창에 직접 쓰고 **분석하기**를 누른다. 파일명이나 컬럼명은 몰라도 된다.
3. **안내형 선택지 (2019년 상권 자료).** **선택지로 고르기** 탭에서 분석 목적, 지역, 업종, 지표, 기간, 제외할 달을 고른 뒤 **선택한 조건으로 분석**을 누른다. 입도객 비교는 선택지가 아니라 질문으로 실행한다.

### 지금 실행할 수 있는 질문

| 목적 | 예시 |
| --- | --- |
| 두 지역 카드 이용금액 비교 | `2019년 연동과 노형동의 한식 음식점업 카드 이용금액을 비교해줘` |
| 월별 추이 | `연동과 노형동의 한식 음식점업 카드 이용금액 월별 추이를 보여줘` |
| 방문 유동인구 | `2019년 연동과 노형동의 방문 유동인구를 월별로 비교해줘` |
| 전체 업종 소계 | `연동 전체 업종 카드 이용금액을 노형동과 비교해줘` |
| 입도객 전년 동월 비교 | `2026년 9월 제주 입도객을 전년 동월과 비교해줘` |
| 두 자료 결합 요청 | `2026년 9월 제주 입도객과 같은 달 연동 한식 카드 이용금액을 결합해줘` (결합하지 않는 이유와 각 자료의 단독 분석을 안내) |

지표·업종처럼 결과가 달라지는 조건이 빠졌거나 뜻이 여러 가지인 경우(예: "여름 빼고")에는 계획 확인 화면에서 라디오 버튼이나 체크박스로 고른 뒤 **이 조건으로 분석**을 누른다.

## 3. 결과 읽기

| 위치 | 내용 |
| --- | --- |
| 맨 위 상자 | 질문에 대한 핵심 한 문장. 엔진이 계산한 값으로 만든다. |
| 결과 보기 방식 | **글로 보기**(쉬운 설명, 정확한 값, 해석 한계, 대표 그래프)와 **수치·그래프로 보기**(대상별 값·차이 카드, 표, 그래프)를 전환한다. 같은 결과를 다시 그리며 조건은 바뀌지 않는다. |
| 분석 계획 / 이번에 바뀐 조건 | 목적·지역·기간·업종·지표·제외 조건과 직전 분석 대비 바뀐 항목 |
| 결과 표 / 그래프 | 위 설명줄에 비교 대상·기간·단위가 있고, 두 항목 비교는 표 마지막 행에 차이가 있다 |
| 근거 | 출처 링크, 실제 관측월, 요청으로 제외한 달, 컬럼별 계산 방법, 품질·한계 알림 |
| 분석 계획·결과 원본(JSON) | 계획과 결과 전체. 공개 자료 집계 결과만 JSON으로 내려받을 수 있다 |

결과는 관측된 차이다. 차이의 원인은 추가 조사가 필요하다. 방문 유동인구는 월 누적 추정치이며 고유 방문자 수가 아니다.

## 4. 조건 바꿔 다시 분석

- 제안 버튼(**7~8월 빼고 다시**, **제외 없이 전체 월로 다시**, **방문인구도 같이 보여줘**, **월별 추이로 바꿔줘**)을 누르거나 화면 아래 고정 입력창에 `노형동만`처럼 쓰고 Enter를 누른다. 새 결과가 나오면 화면이 결과 제목으로 이동한다. 말하지 않은 조건은 직전 분석에서 그대로 이어진다.
- **선택지로 현재 조건 직접 수정**에서 지금 조건을 고쳐 다시 실행할 수 있다.
- **변경 이력**에서 지금까지의 요청과 결과를 본다. 처음부터 다시 하려면 사이드바의 **새 분석 시작 (조건 초기화)**를 누른다.

## 5. 자주 보는 안내와 대처

| 화면 문구 | 원인 | 대처 |
| --- | --- | --- |
| 질문을 입력하거나 예시 질문을 눌러 주세요 | 빈 질문으로 분석하기를 눌렀다 | 질문을 쓰거나 예시를 누른다 |
| …은(는) 이 시연 자료에 아직 등록되지 않았습니다 | 연동·노형동 외 지역을 요청했다 | 연동 또는 노형동으로 바꾼다 |
| 결제 건수·건당 이용액은 이 공개 자료의 등록 지표가 아니어서 … | 2019년 공개 파일에 없는 지표다 | 카드 이용금액 또는 방문 유동인구로 바꾼다 |
| 요청 기간 …은 …의 관측 범위(…) 밖입니다 | 상권 자료(2019-01~2019-12) 밖의 기간을 요청했다 | 2019년 안의 기간으로 다시 요청한다 |
| 두 자료를 결합하지 않았습니다 | 지역 단위(읍면동 / 제주 전체)와 관측 기간이 달라 결합할 수 없다 | 아래 버튼으로 각 자료의 단독 분석을 실행한다 |
| 이 시연은 제주 전체의 월별 입도객 총계만 비교합니다 | 입도객을 지역·내외국인별로 요청했다 | 제주 전체로 다시 요청한다 |
| 연도와 월을 지정해 전년 동월 비교를 요청해 주세요 | 입도객 질문에 연월이나 "전년 동월"이 없다 | `2025년 3월 제주 입도객을 전년 동월과 비교해줘`처럼 쓴다 |
| 연결된 XLSX의 관측 범위가 등록 파일(2001-01~2026-09)과 다릅니다 | 다른 시점의 XLSX를 연결했다 | 2026년 9월 기준 공식 파일을 연결한다 |
| 입도객 XLSX 구조를 확인해 주세요 | 시트명이나 헤더가 공식 파일과 다르다 | 공식 파일을 다시 내려받는다 |

## 6. 제약

- 상권 분석은 2019년, 연동·노형동, 한식 음식점업 또는 전체 업종(관측 소계), 카드 이용금액·방문 유동인구로 한정한다.
- 입도객은 제주특별자치도 전체 월별 확정치의 전년 동월 비교만 지원한다. 비교 가능한 달은 2002-01~2026-09다.
- 두 자료를 결합한 집계는 하지 않는다. 검증된 지역 매핑과 공통 관측 기간이 없기 때문이다.
- 질문 해석은 규칙 기반이다. 등록된 표현에서 벗어난 질문은 확인 질문이나 지원 범위 안내로 이어진다.
- 센터 원자료(카드·유동인구·음식물쓰레기)는 아직 연결하지 않았다. 센터 기준 PC에서의 실행 시간은 측정하지 않았다.
- 질문·원자료·결과는 이 PC에서만 처리한다. 앱은 `localhost`에서만 열리고 사용 통계를 보내지 않는다.
