## 확인하지 못한 것

- 센터 기준 Windows PC(i7-8700, RAM 32GB)에서의 설치·실행 시간.
- 실제 macOS 한글 입력기로 직접 입력(조합 중 Enter는 이벤트로 재현).
- 센터 원자료 연결.
- 짙은 네이비 심볼 로고(`app/assets/logo_navy.png`)가 저장소에 없어 화면은 내장 아이콘으로 확인했다.
