## 화면 조작

- Tab 순서는 질문 입력창 → 분석하기 → 예시·선택지·FAQ 탭 → 예시 버튼이다. ⌘+Enter(Windows는 Ctrl+Enter)로 실행된다.
- 한글 조합 중 Enter(`isComposing`)는 제출하지 않고, 실제 Enter·⌘+Enter는 한 번만 실행했다(분석 횟수로 확인). 실제 macOS 한글 입력기로 직접 타이핑한 확인은 하지 않았다.
- 첫 결과, 고정 입력창의 후속 질문, 제안 버튼 실행 뒤 화면이 결과 제목으로 이동한다. 글로 보기와 수치·그래프로 보기 전환은 분석 횟수와 조건을 바꾸지 않는다.
- 390px 너비에서 가로 스크롤이 없고, 고정 입력창 위로 마지막 내용까지 스크롤된다.

변경 화면은 [`docs/assets/submission-ux/`](assets/submission-ux/)에 있다.
