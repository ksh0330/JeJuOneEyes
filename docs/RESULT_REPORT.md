# 결과 설명자료: 대표 시연 실행 기록

제주데이터허브 공개 CSV(2019년)로 대표 질문과 후속 질문을 앱 화면에서 한 번씩 실행한 기록이다. 기획서 9·10·12쪽(첫 질문 실행, 후속 질문과 조건 변경, 검증과 재현)에 쓰는 화면과 수치를 이 문서에서 가져온다. 모든 캡처는 아래 실행 커밋 한 곳에서 같은 세션으로 찍었다.

공개 CSV는 저장소에 넣지 않았다. 재현하려면 위 페이지에서 같은 파일을 받아 원래 파일명 그대로 `data/local/`에 둔다. 참가자용 허브 목록 엑셀과 센터 예시 엑셀은 이 실행에 사용하지 않았다.

## 실행 절차

1. 시작 화면의 질문 입력창에 `2019년 연동과 노형동의 한식 음식점업 카드 이용금액을 비교해줘`를 입력하고 **분석하기**를 누른다.
2. 결과 화면의 **후속 요청** 입력창에 `7~8월 빼고 다시`를 입력하고 **후속 요청 실행**을 누른다.

## 결과와 검산

| 단계 | 연동 | 노형동 | 차이 (연동 − 노형동) | 실제 관측월 |
| --- | ---: | ---: | ---: | --- |
| 대표 질문 | 33,833,494,533원 | 32,321,443,476원 | 1,512,051,057원 (4.7%) | 12개월 (2019-01 ~ 2019-12) |
| 7~8월 제외 후속 | 28,067,882,813원 | 26,632,168,999원 | 1,435,713,814원 (5.4%) | 10개월 (2019-07, 2019-08 제외) |
| 후속 − 대표 | −5,765,611,720원 | −5,689,274,477원 | | |

- 네 값 모두 [AGENTS.md](../AGENTS.md)의 검산 기준값(공개 CSV를 따로 집계한 값)과 일치한다.
- 두 결과 모두 엔진의 `issues`는 비어 있다. 결과 컬럼 label은 `지역`, `카드 이용금액`(단위 원, 계산 방법 "선택한 업종의 이용금액 합계")이다.
- 출처는 두 화면 모두 `제주데이터허브 상권분석 매쉬업 2019`, 자료 ID `hub.market_mashup_2019`로 표시된다.

20건에는 분석 엔진, 플래너, 실제 CSV 검산, Streamlit `AppTest` 화면 흐름(대표 질문 → 7~8월 제외)이 포함된다. 실제 CSV 테스트는 `data/local/`에 2019년 CSV가 있을 때만 실행된다.

## 해석 범위와 미확인 항목

- 카드 이용금액은 공개 매쉬업 2019년 파일의 한식 음식점업 남성·여성 행 합계다. 결제 건수나 건당 이용액은 이 파일로 계산하지 않았다.
- 결과는 두 지역의 관측된 차이다. 차이의 원인(관광 수요, 점포 수 등)은 이 실행으로 확인하지 않았다.
- Windows 센터 기준 환경(i7-8700, RAM 32GB)에서의 실행과 로컬 SLM 연결은 아직 확인하지 않았다. 현재 플래너는 규칙 기반이다.
- 클린 환경 설치와 최종 ZIP 재실행은 제출 직전에 별도로 수행한다.
