# JeJuOneEyes

제주빅데이터센터 방문자를 위한 자연어 데이터 탐색·분석 Agent입니다. 상인, 도민, 기업·공공기관 실무자가 센터 PC에서 업무 질문을 입력하면, 이용 가능한 데이터를 찾아 전처리·집계하고 표, 차트, 근거로 답하는 것을 목표로 합니다.

현재는 기획과 데이터 사전 확인 단계입니다. 제품 요구사항, 구현 순서, 검증 기준은 [AGENTS.md](AGENTS.md)에 정리했습니다. Claude Code는 [CLAUDE.md](CLAUDE.md)를 통해 같은 지침을 읽습니다.

팀원은 저장소를 클론한 뒤 작업별 브랜치를 만들고 `main`으로 PR을 엽니다. 대회 첨부 엑셀과 센터 원자료는 사용 권한이 있는 환경에서 로컬로 준비합니다.
