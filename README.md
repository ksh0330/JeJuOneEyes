# JeJuOneEyes

제주빅데이터센터 방문자를 위한 자연어 데이터 탐색·분석 Agent입니다. 상인, 도민, 기업·공공기관 실무자가 업무 질문을 입력하거나 안내형 선택지를 고르면, 등록된 자료를 찾아 로컬에서 집계하고 결과와 계산 근거를 보여줍니다.

## 해볼 수 있는 분석

| 분석 | 예시 질문 | 결과 |
| --- | --- | --- |
| 2019년 상권 비교와 재분석 | 2019년 연동과 노형동의 한식 음식점업 카드 이용금액을 비교해줘. 이어서 “7~8월 빼고 다시” | 지역·업종을 유지하면서 제외 월을 반영한 금액과 관측월 |
| 제주 입도객 전년 동월 비교 | 2026년 9월 제주 입도객을 전년 동월과 비교해줘 | 2025년·2026년 9월 확정치, 증감 인원과 증감률 |
| 결합 요청 검토 | 2026년 9월 제주 입도객과 같은 달 연동 한식 카드 이용금액을 결합해줘 | 지역 단위와 관측 기간의 차이, 각 자료로 실행할 수 있는 분석 |

같은 결과를 **글로 보기**와 **수치·그래프로 보기**로 전환할 수 있습니다. 출처, 실제 관측월, 계산 방법은 결과의 근거 영역에서 확인할 수 있습니다. [사용자 매뉴얼](docs/USER_MANUAL.md) · [시연 화면](docs/assets/submission-ux/)

## 로컬 실행

1. [데이터 활용 명세](docs/DATA_SPEC.md)의 공개 파일 두 개를 받아 저장소의 `data/local/`에 둡니다. 2019년 상권 CSV는 원래 파일명을 사용하고, 입도객 XLSX는 `jeju-arrivals.xlsx`로 저장합니다.
2. [앱 실행 안내](app/README.md)에 따라 Python 3.12 가상환경을 만들고 `app/requirements.txt`의 의존성을 설치합니다.
3. 가상환경의 Python으로 저장소 루트에서 `python -m streamlit run app/main.py`를 실행하고 브라우저에서 `http://localhost:8501`을 엽니다.

앱은 규칙 기반 플래너와 로컬 분석 엔진으로 실행됩니다. API 키는 필요 없습니다. 공개 원본 파일과 대회 참가자용 엑셀은 저장소에 올리지 않습니다.
